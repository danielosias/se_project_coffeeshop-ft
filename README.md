# Project 2: Coffee Shop Landing 

Recent additions include: a reservation page, a menu page with items, and an about section with a nice little animation. 

## *Description:* 
This a simple but tasteful webpage about a coffee shop where one can find a basic recipe to make at home or where they can also book a table to get some work done 
in person. 
## *Functions:*
A page that allows users to give and receive information about the coffee shop, video links to see visually to the user. A form page that takes names, number of guest, dates, and emails
for the shop to collect. A menu page of food items served and included are pressable navigation links to jump to the corresponding page.  

## *Deployment:*
Page is mostly ready to go as is, if there is more information to be added that can easily be change in the html.  

### *Improvements:*
This website can use a little styling. It has basic backgrounds and colors, adding more visualizations will make it more alive along with some animations per page.
